# 🩸 Blood Connect

**Blood Connect** is a community-driven mobile application designed to make blood donation **accessible**, **organized**, and **immediate** for everyone who needs it.

We are currently developing this as an evolving concept to support emergency blood needs and foster a reliable network of voluntary donors.

---

## 🌟 Overview

Blood Connect empowers users to:
- **Request blood donations** in emergencies
- **Register as voluntary donors**
- **Stay informed** and prepared in times of need
- **Manage** requests and users with a dedicated **Admin Mode**

This app is still in its **early development phase**, and features are actively being shaped and refined.

---

## 🚀 Features

- 🩸 Raise and view **real-time blood requests**
- 🙋‍♂️ Register as a **voluntary blood donor**
- 📅 View donor history and availability
- 🛡️ **Admin mode** for managing requests and user reports
- 🔒 Secure login with **Firebase Authentication**

---

## 🛠️ Tech Stack

- **Platform**: Android (Jetpack Compose)
- **Language**: Kotlin
- **Backend**: Firebase (Firestore + Auth)
- **Architecture**: MVVM (Model-View-ViewModel)
- **Build Tools**: Gradle (Kotlin DSL)

---

## 📱 How to Use

> This is a native Android application. To run the app:

1. Open the project in **Android Studio (Giraffe or later)**
2. Ensure you're using the latest **compileSdk** and **Gradle plugin**
3. Sync Gradle and build the project
4. Run the app on an emulator or physical device
